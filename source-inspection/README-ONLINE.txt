УГОЛКИ — онлайн-режим

1. В Firebase Console открой проект ugolki-online-cb286.
2. Realtime Database -> Rules.
3. Замени правила содержимым файла firebase-rules.json и нажми Publish.
4. Обнови Android-приложение сборкой из этого проекта.
5. В приложении создай комнату и отправь шестизначный код второму игроку.

Для входа используется Firebase Anonymous Authentication. В Firebase Console -> Authentication -> Sign-in method включи Anonymous.

Важно: это базовая защита для закрытых игр по коду, а не серверная защита от нечестного клиента. Не используй эти правила как основу публичного соревновательного сервиса без серверной проверки ходов.
