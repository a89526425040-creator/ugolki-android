# Уголки — Android project

Android-приложение с автономной игровой доской 10×10, 12 фишками у каждого игрока, классическим оформлением, ходами по четырём прямым направлениям и цепочками прыжков. Игрок ходит первым; компьютер отвечает сразу.

## Сборка APK

Для сборки нужен Android Studio с Android SDK 35 и JDK 17 или новее.

1. Откройте Android Studio → **Open** и выберите эту папку (`ugolki-android`).
2. Дождитесь синхронизации Gradle и установки предложенных компонентов SDK.
3. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Приложение не требует разрешения на интернет: игровая логика находится внутри `assets/index.html`.
